# Published Technical Documentation — Äpre Instruments

I worked at **Äpre Instruments** from **2018 to 2021** as a **Software Engineer and Technical Writer**. I developed proprietary software and authored scientific and engineering documentation, including equipment manuals, software instructions, technical procedures, mathematical explanations, and engineering diagrams.

I personally authored the technical documentation published on Äpre Instruments’ website. The documents below remain on the company’s site. This repository links to those original locations and does **not** republish company-owned files or proprietary source code.

Current website copies may include later company revisions. WordPress upload paths are not treated as publication dates, and employment dates are not presented as document dates.

## Documentation practice represented by this body of work

The published notes are procedure-first: tools required, alignment, focus, measurement, analysis settings, and the failure modes that degrade an interferometric result. That is the same documentation pattern used in the original demonstration projects in this repository—without copying Äpre content, product names, or software.
