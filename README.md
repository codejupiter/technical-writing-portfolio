## Professional focus

I write and typeset documentation for scientific instruments, measurement software, and engineering procedures. The work includes:

- Equipment manuals and operating procedures
- Software instructions for metrology workflows
- Mathematical explanation of measurement methods
- Engineering diagrams and reusable LaTeX templates
- Scientific reports with citations, tables, and uncertainty analysis

Tools: **LaTeX**, **Overleaf**, **TeXstudio**, mathematical typesetting, TikZ technical illustration, custom commands, and shared preambles.
